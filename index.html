SurvAtlas

An offline-first emergency information platform.

View project ↗

Overview

SurvAtlas explores how maps, navigation, reference information and a local AI assistant can remain available without an internet connection. The long-term goal is a portable touchscreen device.

The software currently works offline in development testing. AI refinement, hardware integration and reliability validation are still in progress.

Technologies

Next.js, React, TypeScript, SQLite, MapLibre, Valhalla, Ollama and Docker.

Development

Independent project · Ongoing

SurvAtlas is an experimental project and is not a certified medical device or emergency service.
