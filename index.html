ACTIVE DEVELOPMENT

SurvAtlas.

An offline-first emergency information platform.

↗

SurvAtlas brings locally hosted AI, offline maps and routing, and a reference library into a single touch-first interface. The longer-term goal is a portable, self-contained tablet designed for situations where an internet connection isn't available.
