SURVATLAS.

INFORMATION,
WITHOUT DEPENDENCY.

SurvAtlas is an offline-first emergency information platform that brings local AI, maps, routing and reference material together in one application.

It's an independent engineering project built around a simple idea: useful tools shouldn't always require an internet connection.

THE APPLICATION / 002

OFFLINE
BY DESIGN.

The software combines MapLibre maps, Valhalla routing, locally stored information and an Ollama-based assistant. It uses Next.js, React, TypeScript and SQLite, with ARM64 hardware as a deployment goal.

Offline functionality has been demonstrated during development testing. AI refinement and physical tablet validation are still ongoing.

THE SYSTEM / 003

LOCAL
INTELLIGENCE.

SurvAtlas explores running an AI assistant on local hardware rather than relying on a remote service. The goal is to make reference information and software tools accessible in a self-contained device.

The assistant works offline in development; model quality and hardware performance still need further testing.
